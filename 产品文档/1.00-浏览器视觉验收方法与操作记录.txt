# 1.00 浏览器视觉验收方法

## 能证明什么

浏览器预览可检查页面能否打开、布局、按钮可见性、前端交互和中英文切换。它不能替代 Electron、托盘、安装包、真实 GitHub 或真实中转线路验收。

## 固定步骤

1. 启动预览，记录实际地址和端口。
2. 按“总览 → 线路 → 模型 → 客户端 Key → 统计 → 设置”检查。
3. 每页检查空状态、有数据状态、主要按钮和错误反馈。
4. 切换 English 后检查标题、按钮、弹窗、空状态和错误提示。
5. 对删除、停用、重置、同步冲突检查确认和取消路径。
6. 重开页面，确认数据仍在。

## 视觉标准

深灰背景、紫色主要操作、绿色正常状态、红色危险操作；长文本、英文和窄窗口不溢出；五档思考强度完整显示；Key 卡片、模型分组和统计图清楚；窗口、托盘和底部图标使用同一套资源。

## 截图规则

只保留能证明结果的最少截图。公开前裁切或自然覆盖 Token、密码、账号、私有仓库名和个人路径，不使用影响阅读的马赛克。
