# Cherry AI Connect 1.32：安全更新、恢复修复与思考强度菜单验收

## 版本目标

- 产品正式版本：`1.32.0`
- 网关健康检查版本：`1.32`
- 发布标签：`v1.32`
- 修复范围：1.31 启动崩溃、无上游 API Key 用户的安全更新体验、思考强度视觉和菜单一致性。

## 严重问题修复

### 1.31 启动崩溃

1.31 在启动阶段遇到已消费但本地网关数据缺失的恢复指针时，抛出 `update_recovery_data_missing_after_consumption`，导致 Electron 主进程直接弹出 JavaScript 错误并无法打开。

1.32 增加一次受版本限制的修复恢复：

- 只允许目标版本与当前版本相同，或为当前版本的直接前一小版本。
- 只在备份完整且当前目录为空时恢复。
- 修复恢复最多执行一次，并写入 `recoveryRepairAt`。
- 部分数据目录、旧版本远期备份和再次修复仍保护性停止，避免旧数据静默覆盖。

### 无上游 API Key 的用户

- 安全更新不读取、不要求上游 API Key。
- 本地界面、配置保存和更新下载与上游线路 Key 分离。
- GitHub 超时、GitHub 凭据失败、同步失败、安装包校验失败和线路 Key 缺失分别显示不同原因。
- 没有上游 API Key 时，只有实际调用上游线路才会报告线路 Key 缺失。

## 界面修复

- 顶部和设置页的思考强度名称统一使用金色字体。
- 客户端 Key 卡片的思考强度值在字段标题下方居中。
- 客户端 Key 编辑弹窗的线路和思考强度下拉菜单改为统一的金紫玻璃菜单，不再使用 Windows 原生蓝色菜单。
- 使用统计菜单保持原有独立样式，不纳入本次改动。

- `npm run check`、`npm test`、`npm run renderer:build` 通过。
- 覆盖恢复、已消费指针修复恢复、再次修复保护和旧版本指针拒绝测试通过。
- 安装包启动后 `/health` 返回 `version: 1.32`。
- 1.31 Release 不再作为当前有效发布入口；v1.32 成为唯一 Latest Release。
- GitHub Release 仅包含 v1.32 的安装包、blockmap、Web Demo 和 `latest.yml`。

- 不填写任何上游 API Key 时启动设置页和更新卡片。
