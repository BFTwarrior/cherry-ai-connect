# Cherry AI Connect 1.23 修复计划

更新时间：2026-09-18（UTC+8）

## 首个问题：首次同步后中转站 API 不显示

现象：新设备或空数据首次完成 GitHub 同步后，中转站 API 没有显示；手动创建一条中转站 API 后，已同步的全部 API 才突然出现。

初步方向：检查首次同步完成后的线路数据写入、状态更新、模型目录刷新和页面重新加载触发链，不要用“创建一条新线路”作为临时修复。

验收标准：首次同步成功后无需手动创建线路，页面自动显示全部已同步的中转站 API、模型数量、可用状态和绑定关系；刷新、重启和再次同步后结果保持一致。

规则：1.23 只处理已登记问题；测试中发现的其他问题继续登记到后续版本，不在本版顺手修改。
