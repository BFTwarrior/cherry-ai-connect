# Cherry AI Connect 文档入口 / Documentation index

更新时间：2026-09-17（UTC+8）

## 当前口径 / Current facts

- 正式名称：Cherry AI Connect（中文：Cherry AI 连接中心）。
- 当前公开版本：1.1，GitHub Release 已发布并标记为 Latest。
- 软件定位：为 Cherry Studio 等 OpenAI 兼容客户端提供本地 AI 连接管理。
- 数据目录：安装目录旁的 `data`；不要删除、移动或覆盖。
- 本地端口：安全随机选择 `20000–48999` 内的可用端口。
- 详细请求缓存：达到 50 MiB 后才清理最早明细；永久累计 Token 不受影响。
- GitHub：只上传加密后的用户数据，不上传明文 Key、密码或访问令牌。

## 阅读顺序 / Read in this order

1. `01-使用说明.txt`：普通用户安装、配置、同步和安全提醒。
2. `02-开发维护规则.txt`：代码分层、数据规则、安全边界和发布约束。
3. `03-测试与验收.txt`：自动测试、浏览器验收和真实环境验收方法。
4. `04-1.1实现与发布.txt`：1.1 已实现功能、构建结果和公开下载信息。
5. `05-待验收与后续计划.txt`：当前仍需现场验证的事项及后续记录格式。

## 状态含义 / Status

- 已完成：代码或视觉检查已有证据。
- 待验收：已有实现，尚缺指定测试步骤的结果。
- 待用户验收：需要用户自己的 GitHub、线路、Cherry Studio 或 Windows 环境。
- 待修复：已确认的问题，尚未进入修复完成状态。

## 文件边界 / File boundaries

源码：`electron/`、`gateway/`、`renderer/`、`sync/`；测试：`tests/`；安装包：`dist/`；运行数据：安装目录旁的 `data/`；验收截图：`产品文档/验收证据/1.1/`。

当前文档只保留有效规则和必要证据。历史版本的细节不在文档中重复维护；如需追溯，查看 Git 提交历史和对应 Release。
