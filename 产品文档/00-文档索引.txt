# Cherry AI Connect 文档入口 / Documentation index

更新时间：2026-09-17（UTC+8）

## 当前口径 / Current facts

- 正式名称：Cherry AI Connect（中文：Cherry AI 连接中心）。
- 当前正式版本：1.2，安装包、自动测试、视觉验收和 GitHub Release 已完成。
- 当前公开稳定版：1.2，GitHub Release 已标记为 Latest。
- 数据目录：安装目录旁的 `data`；不要删除、移动或覆盖。
- 本地端口：安全随机选择 `20000–48999` 内的可用端口。
- 请求明细超过 50 MiB 后才清理最早记录；永久累计 Token 不受影响。
- GitHub 只保存加密配置和允许同步的统计数据，不上传明文 Key、密码或访问令牌。
- 同一设备升级或同步不得刷新客户端 API Key；只有全新设备首次恢复时才在本机生成新 Key。
