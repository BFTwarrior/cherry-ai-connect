# Cherry AI Connect 1.2 实现与发布

时间：2026-09-17（UTC+8）  
状态：正式版已发布，GitHub Release 已标记为 Latest。

## 已完成

1. 线路新增、编辑、检测和模型刷新统一进入云同步队列；首次连接 GitHub 仍会立即同步。
2. 一键更新支持下载、SHA-256 校验、更新前同步、本地备份和覆盖安装；异常启动时尝试恢复备份。
3. 同一设备更新或同步绝不刷新客户端 API Key；密钥缺失时保护性停止。只有全新设备首次恢复才在本机生成新 Key。
4. 四步配置改为可拖动悬浮引导；完成状态持久保存，升级、重启和同步后不再出现。
   - 修复拖动后的定位冲突，悬浮窗不再被顶部和底部同时定位而拉出大面积空白。
5. 首页完成配置后仍保持左右双栏；语言卡片取消无意义固定空白。
6. 请求记录支持紧凑单行和详细双行；单行使用局部横向滚动条，选择会保存。
7. 更新卡片重新显示版本、文件、体积、数据保护、下载和校验进度。
8. 深灰负责背景，紫色负责主要交互，金色负责指标和重点，语义状态色继续独立使用。
9. 打包只包含运行需要的源码；未打入开发数据和协议文档。

## 安装包与占用

- 文件：`dist/Cherry-AI-Connect-Setup-1.2.exe`
- 大小：103,003,789 字节（98.23 MiB）
- SHA-256：`DA52B4F421C1623B3A08DED5838253823D93159F3EBF3F637348DA35A262487F`
- 相比 1.1 减少约 0.62 MiB；相比 1.00 减少约 8.9 MiB。
- 打包应用代码约 1.14 MiB，主要体积来自 Electron/Chromium 运行时。
- 烟雾测试 15 秒后，4 个 Electron 进程的私有工作集合计约 104.2 MiB。内存目标未明显改善，不能宣称已经轻量化。

若要达到 20–30 MiB 安装包和更低内存，需要未来评估 WebView2、Tauri 等运行框架迁移；这不是继续压缩现有 Electron 包即可安全完成的工作。
