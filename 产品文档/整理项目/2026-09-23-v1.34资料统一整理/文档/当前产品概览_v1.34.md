# Cherry AI Connect 当前产品概览

适用：v1.34　状态：GitHub Latest　更新时间：2026-09-23

## 产品与模块

Cherry AI Connect 在本机提供 OpenAI 兼容连接服务，管理上游线路、模型、客户端 Key、用量和可选云同步。Electron 管桌面生命周期与更新；Gateway 只监听 `127.0.0.1` 并处理鉴权、转发和统计；Renderer 提供工作台；`sync/` 分层负责同步协议、GitHub、保险库和加解密。

## 数据与凭证

- 正式版运行数据位于安装目录旁 `data/`；配置、客户端 Key、统计账本、凭证和保险库均不能因更新或排错而清空。
- GitHub PAT 用于私有仓库访问；保险库密码/恢复码用于保护云端敏感配置；上游 API Key 只供实际上游请求使用，三者不可混用。
- 用量和基础元数据独立同步；上游线路默认不同步，主动开启后加密。失败时保留最后有效数据，不把部分成功显示成全部成功。
- 同设备更新、重启和同步不生成新客户端 API Key；新设备首次恢复可生成本机 Key。
