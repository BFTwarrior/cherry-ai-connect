版本：v1.40.1

本次目标
修复“开始更新后切换到其他页面，再回到设置页，界面显示仍在检查更新，必须再次点击更新进度才出现”的状态恢复问题。

修复内容
1. 设置页重新挂载时，先读取主进程的权威更新快照，再决定是否执行可用性检查；后台更新进行中时，不再让自动检查覆盖更新状态。
2. 更新任务在等待网关重置之前就写入 syncing 运行快照，避免页面切换期间读到旧的 idle、completed 或 error 状态。
3. 更新仍由主进程持续执行，页面卸载只影响显示组件，不会取消下载任务。

- npm test：必须全部通过。

- npm run renderer:build：必须通过渲染层构建。

- npm run dist：生成独立的 v1.40.1 Windows x64 安装包，并核验大小不超过 100 MB。
- 发布后核验 GitHub Release、安装包、blockmap、latest.yml 与 Web Demo 资产状态均为 uploaded。
