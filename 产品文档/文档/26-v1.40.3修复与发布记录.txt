# v1.40.3 修复与发布记录

更新时间：2026-09-25（UTC+8）

范围：仅处理本次明确提出的四项软件问题；GitHub 主页改版已作为独立文档提交，不计入本版本功能范围。

## 一、本版本修复内容

### 1. 菜单栏线路筛选目录

- `Codex Official / Codex 官方` 固定为“全部线路”后的第一个选项。
- 当前选择某一条线路时，只裁剪统计结果和历史记录，不再从下拉目录中删除其他线路。
- 中转线路继续按名称排序。

### 2. Cherry Studio 检测并启用兼容性

- 保留已有“模型目录不可用但线路仍可用”的兼容状态，不把目录探测错误直接等同于上游线路不可用。
- 兼容少数上游返回 `model` 或 `slug` 字段而不是标准 `id` 的模型目录格式。
- `/v1/models` 在缺少探测时间时提供有效的 Unix 时间元数据，避免 Cherry Studio 因 `created=0` 误判目录响应。
- 不改写真实模型名，不把兼容占位符强行发送给上游。

### 3. Codex 官方十亿级 Token 显示口径

- 官方 sessions 记录明确标记为 `session-cumulative`。
- 使用统计中显示为“累计输入 Token / Session input”，并标注“官方会话累计 / Cumulative session total”。
- 不对官方服务返回的累计值进行除法、重复累加或虚构单次请求值；缓存输入仍单独显示。

### 4. 使用统计来源按钮卡顿

- 来源切换与五秒轮询共用请求序列，旧请求会被取消或忽略，旧结果不会覆盖新选择。
- 统计记录数字和日期格式化器按语言复用，避免每个单元格重复创建格式化对象。
- 历史记录使用浏览器的可见区域渲染优化，保持现有字段和统计口径不变。
