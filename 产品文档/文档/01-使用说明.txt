# Cherry AI Connect 使用说明

适用版本：公开 v1.37；当前候选 v1.37.1（未发布）　更新时间：2026-09-25（UTC+8）

## 快速配置

1. 在“中转站线路”新增地址和上游 API Key，先检测线路。API Key 仅在实际调用上游线路时需要；本地界面和安全更新不要求填写。
2. 在“模型目录”同步模型并确认线路分组。
3. 在“客户端 Key”生成一个 Key，并绑定一条线路。
4. 将本地 API 地址、客户端 Key 和模型填入 Cherry Studio，发送测试请求。

一个客户端 Key 只能绑定一条线路。Key 名称默认跟随线路名称；手动改名后不会再被线路改名覆盖。

## 常用功能

- 线路：新增、编辑、停用、删除、单条检测、全部检测和刷新模型。
- 模型：按线路分组，每组可独立折叠；支持搜索。
- 统计：支持 24 小时至 180 天和永久累计；请求记录可切换单行/双行，明细清理不影响永久累计。
- Codex 官方：当前工作树可单独读取本机 Codex 用量来源；该来源与中转站统计分开显示、分开缓存，服务不可用时显示不可用，不伪造为零用量。
- 端口：端口冲突时使用“重置连接服务”，软件会更换端口并刷新本地 API 地址。
- 1.21 起：彻底删除四步配置引导模块；首次同步完成后会自动刷新线路、模型和客户端 Key。

## GitHub 云同步

使用自己的 GitHub 私有同步仓库。Fine-grained token 只需设置：

| 项目 | 选择 |
|---|---|
| Repository access | `Only select repositories` |
| Repository | 只选专用私有同步仓库 |
| Contents | `Read and write` |
| Metadata | 保持系统要求的 `Read-only` |
| 不需要 | `All repositories`、`Actions`、`Administration`、`Secrets` 等无关权限 |

令牌只显示一次，立即复制到软件，不要放进聊天、截图、Issue 或公开仓库。更换令牌时，先创建同仓库、同权限的新令牌，确认同步成功后再撤销旧令牌；仓库本身不用重建。

GitHub 访问令牌、保险库加密密码/恢复码、上游 API Key 是三类不同凭证，不能互相替代。同步冲突时，已解锁的本机保险库选择“保留本机”无需重复输入密码；首次创建保险库或恢复云端密文仍需要对应凭证。

自动同步每 30 分钟检查一次；应用启动、退出、窗口关闭、配置变更、线路检测、模型刷新和手动操作可触发去重同步。设置页显示上次/下次同步时间，使用 UTC+8。

中转站 API 默认不上传；只有在云同步设置中主动开启后才会要求备份加密密码并加密同步。用量与基础元数据独立同步，不依赖保险库；读取云端敏感配置时可以取消恢复。

同一设备更新、重启或同步时，客户端 API Key 必须保持不变。只有全新设备首次恢复时，才允许在新设备生成本机 Key。

## Codex 官方统计的当前口径

界面中的“Codex 官方 / Codex Official”是产品内来源标签，不等于 OpenAI 账户级用量总账。v1.40.3 只读本机 `http://127.0.0.1:43189` 的 `codex-usage` loopback API，读取 summary、timeseries 和请求级 JSON export。没有请求级 export 时不显示官方明细，不回退读取 sessions，避免把会话累计值误显示为单次请求。不读取 `auth.json`、会话 JSONL、聊天正文或密钥，也不写入中转站 usage ledger。

请求历史中的 Codex 官方每一行代表一次模型请求，使用该请求自己的 `usage.input_tokens`、`cached_input_tokens`、`output_tokens` 和 `total_tokens`。sessions 接口中的 `usage` 是整个会话累计值，不再用于新版明细行。上下文压缩本身会产生新的模型调用和 Token 消耗，若统计器把它记为一次请求，其用量会进入对应单次记录；它不能被误并入上一条请求或当成整个会话的一次输入。

官方来源使用独立的 45 MiB 裁剪目标和 50 MiB 硬上限内存缓存。没有 HTTP 状态、耗时或流式字段时，页面显示“未知”；本机服务不可用时显示“已开启但不可用”，不能把故障写成 0 条或把数据合并到某条中转线路。

按 OpenAI 官方文档，Codex `/usage` 用于账户令牌活动，`/status` 用于当前会话、上下文和限额。本产品的本机只读适配器不是上述账户级视图的替代，不提供云同步、备份或跨设备恢复。参考：

- https://learn.chatgpt.com/docs/developer-commands
- https://learn.chatgpt.com/docs/app-server

## 安全

正式版数据位于程序目录同级的 `<程序目录名>-data/`，旧版可能还留有程序目录内的 `data/` 和更新恢复备份。这些都不是普通缓存，可能包含线路配置、客户端 Key、永久统计和未同步记录；核对前不要删除或用旧数据覆盖。若启动时提示只找到旧备份，先看备份版本与时间，再决定是否恢复，恢复后继续核对云同步中是否存在较新的记录。
