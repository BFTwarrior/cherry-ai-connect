3. **再查**：补充官方缓存跨模型全局预算、深分页不可伪造、网关固定回环监听、同步并发合并、Key/vault 提交前校验、更新恢复路径/版本/关键数据校验和对应回归测试。
4. **优化**：清理已确认失效的 CSS 最终覆盖层和无效状态变量，修正文档版本与路径混用，保留历史证据和未完成现场验收项。
5. **终查**：完成 `npm test` 75/75、`npm run check`、`npm run renderer:build`、`npm run web-demo:build`、`npm run dist`、`git diff --check`；XMind 新版验证为 0 errors、0 warnings。真实安装覆盖、更新切页和跨设备同步仍需目标 Windows 设备现场验收。

## 关键边界

- `Codex Official` 只读本机 loopback API，与 Relay ledger 分离；官方缓存目标 45 MiB、硬上限 50 MiB，跨模型共享预算。
- 官方 sessions 是会话聚合记录，缺少 HTTP 状态时显示未知；读取超过可证明前缀时标记不可用，不伪造深页数据。
- 网关固定绑定 `127.0.0.1`，不接受 `GATEWAY_HOST` 外部注入，避免管理 API 意外暴露。
- 不删除 Electron 图形、媒体、SwiftShader、Vulkan 或 Chromium 运行库；粒子效果和跨设备渲染优先于不安全的体积削减。
- 分发目录已统一：项目根目录的 `安装包/桌面版/` 与 `安装包/网页演示/` 只保留当前 v1.37.1 候选；旧 v1.00-v1.23 资产移入对应 `安装包/历史/`，保留追溯但不作为当前入口。
