状态：已构建，待 GitHub 发布验证

本次目标
在主页增加明显的 GitHub API Key 配置入口，让用户不必先进入云同步设置即可快捷打开 GitHub Fine-grained Personal Access Token 配置页面。

界面调整
1. 主页欢迎区域新增“配置 GitHub API Key / Configure GitHub API key”按钮。
2. 按钮使用独立的金色强调边框与紫金渐变，和主页主操作区保持一致但能够被快速识别。
3. 点击后通过 Electron 外部链接打开 GitHub Fine-grained Personal Access Token 页面。
4. 设置页原有“创建令牌”入口同步改用同一个 Fine-grained Token 页面，避免两个入口指向不同授权方式。

安全边界
- 这里只负责打开 GitHub 官方配置页面，不在应用中读取、显示或保存令牌。
- 令牌权限仍按最小权限配置：指定私有同步仓库，Contents 为 Read and write，Metadata 为 Read-only。

核验范围
- npm test：必须全部通过。
- npm run check：必须通过 TypeScript 检查。
- npm run renderer:build：必须通过渲染层构建。
- npm run web-demo:build：必须通过 Web Demo 构建。
- npm run dist：生成不超过 100 MB 的 Windows x64 安装包。
