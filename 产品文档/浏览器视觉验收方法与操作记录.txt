# 浏览器视觉验收方法

更新时间：2026-09-17（UTC+8）

## 用途与边界

浏览器预览使用临时假线路、假请求和临时数据目录，可检查布局、交互、统计和中英文，不会读取正式配置。它不能替代 Electron 标题栏、托盘、安装包、真实 GitHub 或真实线路验收。

## 操作

1. 执行 `npm run renderer:build`。
2. 执行 `node tests/usage-preview.mjs`。
3. 打开 `http://127.0.0.1:4173`。
4. 依次检查总览、线路、模型、客户端 Key、统计、设置和 English。
5. 停止预览后临时数据自动删除。

- 配置完成后四步引导已消失。
- 单条/全部线路检测、模型折叠、两层请求记录、更新卡、同步时间及 English 已检查。
- 默认 Electron 窗口另行核对，标题栏、系统按钮和约 1280×840 布局正常。
