三、1.00 实际完成的产品功能
======================================================================

1. 产品与桌面行为
--------------------------------------------------------------------
- 正式名称：Cherry AI 连接中心；英文名：Cherry AI Connect。
- Electron Windows 桌面应用，React + TypeScript + Vite 界面。
- 深灰和紫色视觉，中英文切换，自定义二次确认窗口。
- 支持托盘、开机自启、启动隐藏、关闭到托盘和手动检查更新。
- 普通界面尽量使用“连接服务”，代码和历史兼容路径仍可保留 gateway 技术名称。

2. 线路、模型与客户端 Key
--------------------------------------------------------------------
- 可新增、编辑、测试、停用和删除多条上游线路。
- 每个客户端 Key 只绑定一条线路，Cherry Studio 不直接保存真实上游 Key。
- 新建客户端 Key 默认使用绑定线路名称；只要用户没有手动改名，切换线路后继续同步
  名称；用户手动改名后永久停止自动改名。
- 客户端 Key 支持复制 Key、复制本地 API 地址、测试、编辑、停用、启用和删除。
- 旧版不能读取完整 Key 时只显示“重新生成”，不再显示无意义的“旧版 Key”按钮。
- 模型目录按线路分组，不把所有模型堆成一个不可读列表。
- 思考强度固定五档：low、medium、high、xhigh、max；请求时写入对应上游字段，
  不是只修改界面标签。

3. 本地连接服务与随机端口
--------------------------------------------------------------------
- 只监听 127.0.0.1，不默认开放到局域网或互联网。
- 支持 OpenAI 兼容的 /v1/models、/v1/chat/completions 和 /v1/responses。
- 正常启动优先复用仍可用的保存端口。
- 手动重置时使用系统安全随机数，在 20000-48999 共 29,000 个候选端口中选择，
  跳过当前端口和已占用端口。
- 重置只更换本地端口并重启监听器；线路、模型、客户端 Key、思考强度、统计和
  云端 datasetId 均保留。旧 API 地址失效，用户需要复制新地址到 Cherry Studio。

4. 使用统计
--------------------------------------------------------------------
- SQLite 保存请求明细、永久累计、设备计数器、同步队列和同步运行记录。
- 永久累计没有时间限制，包括请求数、输入、输出、缓存读取、缓存创建、总 Token、
  成功和失败；删除旧明细不得减少永久累计。
- 趋势范围支持 24 小时、7 天、30 天、90 天和半年。
- 实时记录表单页展示最新 200 条；“200”只是界面单页数量，不是存储上限。
- 本机明细缓存最大 50 MiB。只有超过 50 MiB 后才删除最早明细，回落到约 45 MiB。
- 页面显示当前缓存占用、50 MiB 上限、永久累计、折线图、缓存命中率和请求表。

5. GitHub 私有云同步
--------------------------------------------------------------------
- 当前候选版使用用户创建的 GitHub 访问令牌（PAT），不是 OAuth Device Flow。
- PAT 经 Electron safeStorage / Windows DPAPI 保护后保存在本机，不进入源码、日志、
  云端附件或截图。
- 程序自动创建/使用用户专用私有仓库和固定 cherry-sync Release；检测到公开仓库时
  保护性停止。
- JSON/JSONL 上传前 gzip 压缩；安全线路配置和上游 Key 使用 Argon2id、DEK/KEK、
  AES-256-GCM 信封加密。
- 完整客户端 Key、提示词、回答、Authorization、Cookie、密码、恢复码和 GitHub
  Token 永不上传。
- 使用记录按 eventId 去重；永久统计按 deviceId + deviceEpoch 的 G-Counter 合并。
- 数据附件不可变，manifest 最后提交；上传后重新下载并校验大小和 SHA-256。
- 中断候选不会清空本机 outbox；保留最近 4 代有效 manifest，24 小时后才清理孤儿。
- 800 个 Release 资产时警告，900 个时先安全垃圾回收，仍超限则停止新增代。
- 自动检查周期为 30 分钟；启用、关闭、启动、退出、手动同步、恢复、账户变化、
  vault 和安全线路变化会额外触发同步尝试。
- 配置冲突必须让用户选择“保留本机”或“恢复云端”，不能静默覆盖上游 Key。
- 错误密码不能写入远端 vault，也不能覆盖本机配置。
