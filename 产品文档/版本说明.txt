# Cherry AI Connect 版本说明

## 1.00

当前公开版本。完成桌面外壳、本地连接服务、线路与客户端 Key 管理、模型目录、五档思考强度、使用统计、累计 Token、GitHub 加密同步、检查更新、托盘和网关重置。

安装包通过 GitHub Release 发布。1.00 的自动化检查已通过；真实 GitHub、真实中转线路、Cherry Studio 和干净 Windows 安装仍按测试说明完成现场验收。

## 0.4.x

早期开发版本，仅作为背景，不再作为当前功能和测试依据。旧版详细记录已从产品文档中移除。

## 版本规则

每次发布必须同步更新界面版本、README、安装包名称、Release 标签、测试说明和实现报告。未验证的功能不得写成已完成。
