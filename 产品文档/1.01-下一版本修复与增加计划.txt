# Cherry AI Connect 1.01 修复与增加计划

制定时间：2026-09-16（UTC+8）

## 目标

优先闭环 1.00 的现场验收，减少用户操作，不扩大无关功能范围。

## P0：稳定与安全

- GitHub Token 过期、撤销、权限不足、仓库不存在、断网分别提示。
- 新 Token 先同步成功，再允许废弃旧 Token；失败不覆盖本地数据。
- 启动、退出、开启/关闭和 30 分钟同步进入同一队列，避免并发覆盖。
- 同步包压缩并加密；记录最后成功时间和失败原因，但不记录明文 Token。
- 保持数据在安装目录旁的 `data`；明确提醒不要误删。
- 50 MiB 只限制详细请求缓存，不删除累计 Token、线路或客户端 Key。
- 用真实线路和 Cherry Studio 核对模型、五档思考强度、Token、缓存和错误提示。

## P1：桌面与界面

- 核验窗口、托盘、底部品牌图标使用同一资源。
- 核验开机自启、启动隐藏、关闭到托盘、托盘恢复和退出。
- 重置网关：停止旧监听、重新选择 `20000–48999` 的可用端口、刷新所有 API 入口。
- 所有页面、弹窗、空状态、错误提示覆盖中文/English。
- 客户端名称默认跟随线路；手动改名后锁定。
- 统一删除、停用、重置、同步冲突的确认窗口。
- 统计支持来源/模型/线路筛选，统一 UTC+8，图表和表格使用同一数据源。

## P2：可选增强

脱敏诊断包、本地备份与差异摘要、代码签名信息、更多异常恢复自动化测试。

## 完成标准

自动化测试和新增测试通过；真实 GitHub、真实线路、Cherry Studio、安装/卸载和托盘验收通过；README、界面、安装包、Release、测试文档使用同一产品名和版本号；未验证项目仍标为“待验收”或“待用户验收”。
