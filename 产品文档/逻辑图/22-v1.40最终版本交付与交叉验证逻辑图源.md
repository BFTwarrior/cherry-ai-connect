## Scope & Non-goals
### Included reliability fixes
#### Update state survives page changes
> Main-process progress snapshots are written before the pre-update sync wait; remounted pages use active and monotonic sequence values.
#### Cherry Studio route health is honest
> Cached models may preserve a callable route when catalog discovery is unsupported or rate-limited; unverified network/auth/5xx failures are not labeled ready.
#### Sync and usage boundaries remain separate
> Update pause gates all sync entry points; official Codex records do not enter the relay ledger; only 2xx is usage success.
### Explicit non-goals
#### No architecture migration
> This release does not migrate Electron to Tauri or rebuild the product for Apple platforms.
#### No automatic GitHub publication
> Local packaging is completed first; GitHub Release publication is a separate authorized action.
