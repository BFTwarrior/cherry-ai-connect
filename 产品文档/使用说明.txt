# Cherry AI Connect 使用说明

## 第一次配置

1. 在“中转线路”新增地址、上游 Key 和默认思考强度，点击“测试连接”。
2. 刷新模型目录。
3. 在“客户端 Key”生成一个 Key，并绑定一条线路。
4. 将程序显示的本地 API 地址、客户端 Key 和模型填入 Cherry Studio。

一个客户端 Key 只能绑定一条线路。默认名称跟随线路；手动改名后不再同步。

## 常用功能

- 复制 API/Key：在客户端 Key 页面点击对应复制按钮。
- 编辑、停用、删除：删除前会确认，停用可恢复。
- 思考强度：`low / medium / high / xhigh / max`；上游不支持时按提示处理。
- 重置网关：换一个随机本地端口，刷新 API 地址并结束旧监听，用于处理端口冲突。
- 使用统计：查看实时、时间范围和累计 Token；累计总量不会因清理详细缓存而减少。

## GitHub 云同步

使用自己的私有仓库和 Fine-grained Token。只选同步仓库，权限选 `Contents: Read and write`，`Metadata: Read-only` 保留默认项。同步内容是加密备份，不上传明文 Key、密码或客户端凭证。

开启/关闭、启动/退出和周期任务会同步。Token 过期或撤销时创建新 Token，替换后先同步成功，再废弃旧 Token。

## 安全提醒

数据在安装目录旁的 `data` 文件夹，请不要误删或移动。不要公开上游 Key、data、同步仓库或完整日志；遇到错误先看提示，不要直接删除 data。
