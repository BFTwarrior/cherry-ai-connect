## 浏览器验收 / Browser visual check

浏览器预览使用临时假线路、假请求和临时数据，只用于检查页面布局、交互、统计和双语显示，不读取正式配置。它不能替代真实 GitHub、真实线路、Cherry Studio、Electron 标题栏、托盘和安装器验收。

1. 构建前端：`npm run renderer:build`。
2. 启动预览：`node tests/usage-preview.mjs`。
3. 打开：`http://127.0.0.1:4173`。
4. 依次检查总览、线路、模型、客户端 Key、统计、设置和 English；特别看默认窗口是否溢出、按钮是否遮挡、记录字段是否完整。
5. 停止预览；临时数据应自动清理。截图公开前必须确认没有令牌、密码、真实仓库、个人路径或真实日志。

## 真实环境验收 / Real-environment acceptance

以下项目必须在用户自己的环境中执行，不能用浏览器假数据代替：

| 项目 / Area | 必测内容 / Required checks |
|---|---|
| GitHub | 首次同步、恢复、30 分钟同步、上次/下次时间、换 Token、过期、撤销、断网、冲突 |
| 线路与客户端 | 真实线路、模型、五档思考强度、流式首字、Token、缓存、错误提示和客户端 Key 一对一绑定 |
| Windows | 安装、覆盖安装、卸载、托盘恢复、开机自启、启动隐藏、关闭到托盘同步、真正退出同步 |
| 数据清理 | 超过 50 MiB 后只清理最早明细；永久累计、线路和客户端 Key 仍存在 |

记录结果时只写：版本、UTC+8 时间、步骤、实际结果和脱敏截图。常见错误优先检查：`401` 上游 Key，`403` 权限/额度，`404` 仓库或模型名称；不要直接删除 `data`。
