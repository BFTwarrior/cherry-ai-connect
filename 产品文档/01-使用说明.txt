# Cherry AI Connect 使用说明

适用版本：1.31 及后续兼容版本　更新时间：2026-09-22（UTC+8）

## 快速配置

1. 在“中转站线路”新增地址和上游 Key，先检测线路。
2. 在“模型目录”同步模型并确认线路分组。
3. 在“客户端 Key”生成一个 Key，并绑定一条线路。
4. 将本地 API 地址、客户端 Key 和模型填入 Cherry Studio，发送测试请求。

一个客户端 Key 只能绑定一条线路。Key 名称默认跟随线路名称；手动改名后不会再被线路改名覆盖。

## 常用功能

- 线路：新增、编辑、停用、删除、单条检测、全部检测和刷新模型。
- 模型：按线路分组，每组可独立折叠；支持搜索。
- 统计：支持 24 小时至 180 天和永久累计；请求记录可切换单行/双行，明细清理不影响永久累计。
- 端口：端口冲突时使用“重置连接服务”，软件会更换端口并刷新本地 API 地址。
- 1.21 起：彻底删除四步配置引导模块；首次同步完成后会自动刷新线路、模型和客户端 Key。

## GitHub 云同步

使用自己的 GitHub 私有同步仓库。Fine-grained token 只需设置：

| 项目 | 选择 |
|---|---|
| Repository access | `Only select repositories` |
| Repository | 只选专用私有同步仓库 |
| Contents | `Read and write` |
| Metadata | 保持系统要求的 `Read-only` |
| 不需要 | `All repositories`、`Actions`、`Administration`、`Secrets` 等无关权限 |

令牌只显示一次，立即复制到软件，不要放进聊天、截图、Issue 或公开仓库。更换令牌时，先创建同仓库、同权限的新令牌，确认同步成功后再撤销旧令牌；仓库本身不用重建。

低频同步默认每 30 分钟一次；启动、退出、右上角关闭、线路变更、线路检测和模型刷新会进入去重同步队列。设置页显示上次/下次同步时间，使用 UTC+8。

中转站 API 默认不上传；只有在云同步设置中主动开启后才会要求密码并加密同步，读取云端时可跳过恢复，不影响用量数据同步。

同一设备更新、重启或同步时，客户端 API Key 必须保持不变。只有全新设备首次恢复时，才允许在新设备生成本机 Key。

## 安全

`data/` 不是普通缓存，可能包含线路配置、客户端 Key、永久统计和未同步记录。处理问题前先备份，不要删除整个 `data/` 来“修复”同步。
