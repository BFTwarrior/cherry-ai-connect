# Cherry AI Connect 1.1 文档索引

更新时间：2026-09-17（UTC+8）

## 当前口径

- 正式名：Cherry AI Connect（中文：Cherry AI 连接中心）。
- 本机已构建并发布版本：1.1；GitHub 当前公开版本为 1.1，主页和 Release 下载链接均已更新。
- 客户端 Key 一对一绑定中转线路，思考强度五档：`low / medium / high / xhigh / max`。
- 本地端口：`20000–48999`；“重置网关”会换端口并清理旧监听。
- 数据目录：安装目录旁的 `data`；不要误删。
- 详细缓存上限 50 MiB；累计 Token 不受缓存清理影响。
- GitHub 只保存加密备份，不保存明文 Key 或密码。

## 阅读顺序

1. `产品目标.txt`、`产品要求.txt`
2. `使用说明.txt`
3. `测试人员完整说明.txt`
4. `1.1-实现现状与验收报告.txt`
5. `UI小功能测评问题清单.txt`
6. `浏览器视觉验收方法与操作记录.txt`

`版本说明.txt` 和 `踩坑记录.txt` 是快速参考，不是当前实现的唯一依据。

## 状态含义

- 已完成：代码检查完成。
- 待验收：代码已修复，等待测试。
- 待用户验收：需要真实账号、线路或设备。
- 待修复：已确认缺陷未修复。

## 文件边界

源码在 `electron/`、`gateway/`、`renderer/`、`sync/`；测试在 `tests/`；安装包在 `dist/`；运行数据在安装目录旁的 `data/`。1.1 验收截图在 `验收证据/1.1/`，公开前必须脱敏。
